# TOP-Library
Stands for The Odin Project Library, it is my interpretation and subsequent approach to [TOP's Library project](https://www.theodinproject.com/lessons/node-path-javascript-library).

For the website interface, the theme followed [Vev's Monochromatic Minimalism](https://www.vev.design/blog/dark-mode-website-color-palette/)
The font ([Clarity City](https://fonts.google.com/specimen/Clarity+City?preview.script=Latn)) is taken from Google Fonts.
